  VPG dataset includes 12 synthetic sets and 24 read sets. 
  Half of each type of sets are indoor scenes and another half are outdoor street-view scenes.
  
  The 12 synthetic sets (e.g., S01-S12) are generated by 3Ds Max 2014. Each directory contains the image files ##.jpg/png, the camera parameters 
  (row1-row3: rotation; row4: translation) camera-##.txt, the stitching graph S##-Stitch-Graph.txt, and the matched feature point positiones saved 
  in m##-##.txt. Note that for synthetic image sets, directly conducting feature matching algorithms (e.g., SIFT) on them may fail since the 
  homogeneous texture of these scenes. We therefore generate the feature correspondences using the ray intersection technique provided by the 
  3Ds Max software.
  
  For 24 real sets, each directory only contains image files and the stitching graph.
  
  Please kindly cite our paper if you use our dataset:
  
  Kai Chen, Jian Yao, Jingmin Tu, Yahui Liu, Yinxuan Li, and Li Li, Vanishing Point Guided Natural Image Stitching,
  submitted to IEEE Transactions on Image Processing, 2019.
